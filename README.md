# 🌧️ Rain Prediction ML System

A machine learning project that predicts whether it will rain tomorrow based on weather conditions such as temperature, humidity, wind speed, precipitation, cloud cover, and pressure.

---

## 🚀 Project Overview

This project uses a **Logistic Regression model** trained on historical weather data to predict rain. It includes:

- Data preprocessing and encoding
- Model training and evaluation
- Feature importance analysis
- A **Streamlit web app** for interactive predictions

---


## 📊 Dataset

The dataset includes the following features:

- Date
- Location
- Temperature
- Humidity
- Wind Speed
- Precipitation
- Cloud Cover
- Pressure
- Rain Tomorrow (target variable)

## 🧠 Model Training

The model is trained using:

- **Algorithm:** Logistic Regression  
- **Preprocessing:** Label Encoding (Location)  
- **Split:** 80% training, 20% testing  

### Key Features Used:
- Location  
- Temperature  
- Humidity  
- Wind Speed  
- Precipitation  
- Cloud Cover  
- Pressure  

---
